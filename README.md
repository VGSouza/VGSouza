# Victor Souza

Desenvolvedor full stack. Trabalho com Angular, .NET, Java, JavaScript, TypeScript e MySQL, e ultimamente tenho construído bastante coisa serverless com Cloudflare Workers e D1.

Gosto de pegar o problema inteiro: levantar o que a operação precisa, desenhar o banco, fazer a API e a tela, e deixar rodando em produção.

## Projetos

- [agendamento-clinica](https://github.com/VGSouza/agendamento-clinica): agendamento para clínica com controle de concorrência em tempo real (Angular, NestJS e MySQL)
- [central-ocorrencias](https://github.com/VGSouza/central-ocorrencias): gestão de ocorrências de segurança patrimonial com planos de ação, notificações e dashboard
- [atendimento-ocupacional](https://github.com/VGSouza/atendimento-ocupacional): gestão de atendimentos de saúde ocupacional com SLA em dias úteis
- [psico360](https://github.com/VGSouza/psico360): avaliação de riscos psicossociais conforme a NR-1, com matriz de risco e validação por ergonomista
- [previne](https://github.com/VGSouza/previne): PWA de EHS para unidades de saúde
